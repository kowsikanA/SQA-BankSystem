# SQA-Banking System

A two-part banking application developed using Python and Shell scripting, created for the Software Quality Assurance course at Ontario Tech University. The project follows Agile development principles with a strong emphasis on software quality practices.

## 📌 Project Overview

This system simulates the core operations of a banking environment through:

- **Front-End (ATM Terminal):**  
  A console-based interface for executing banking transactions such as login, deposit, withdrawal, transfer, and paybill.

- **Back-End (Batch Processor):**  
  A nightly batch processor that reads transaction logs and updates the master account file accordingly.

## ✅ Features

- Session-based user management (admin and standard users)  
- Support for a wide range of banking operations with enforced rules and constraints  
- Transaction log generation and processing for accurate and secure account management  

## 🛠️ Software Quality Assurance Practices

- Test-driven development using custom-designed test cases  
- Agile workflow: iterative development, pair programming, and frequent feedback cycles  
- Code quality maintained through version control, modular design, and team code reviews  
- Strong emphasis on documentation, maintainability, and reliability
